
# Bank Loan Analysis Dashboard

## Project Overview

This project focuses on analyzing bank loan applicant data to identify patterns among customers facing difficulty in repayment. The objective was to derive actionable insights that help reduce financial risk and improve lending decisions.

---

## Business Problem

Banks face challenges in identifying loan applicants who may struggle to repay installments. The project analyzes customer behavior, income trends, loan status, and demographic factors to support better credit risk assessment.

---

## Tools & Technologies Used

* Microsoft Excel
* Data Cleaning
* Exploratory Data Analysis (EDA)

---

## Key KPIs

* Total Loan Applications
* Loan Approval Rate
* Default Percentage
* Income Distribution
* Credit Risk Segmentation

---

## Process Followed

1. Data Cleaning and Preprocessing
2. Handling Missing Values
3. Exploratory Data Analysis
4. KPI Development
5. Dashboard Creation
6. Insight Generation

---

## Key Insights

* Customers with lower income levels showed higher repayment risk.
* Certain occupation groups had higher default probability.
* Loan approval rates varied significantly across customer segments.
* Younger applicants showed comparatively better repayment consistency.
